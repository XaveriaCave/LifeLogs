ArshMind — Full-Stack Upgrade Spec
Transform the current static HTML/localStorage prototype into a production-grade web app with persistent user accounts, real-time AI projections, social features, and a monetizable SaaS tier. Everything here maps directly to implementable code.

Core upgrades from prototype → product
Persistent Accounts
Replace localStorage with a real database. Users own their profile, projections, and history across devices. OAuth + email auth.
Real AI Engine
Replace hard-coded scenario modifiers with a Claude/GPT-backed projection engine that reasons about the user's specific context, city, and goals.
Community & Benchmarks
Anonymous peer comparison. "Doctors in Bangalore with 3 years experience save X on average." Cohort benchmarking.
Live Financial Sync
Connect to bank accounts via Account Aggregator (India). Auto-update savings and income in projections. Net worth tracker.
Milestone Alerts
Push/email notifications when a goal window opens, savings hit a target, or a recommended action is overdue.
Monetization Layer
Free tier with 1 scenario. Pro tier unlocks all 6 paths, AI advisor chat, PDF export, and custom goal creation.
Technology
Full-Stack Tech Stack
Chosen for India-market speed, free tiers during MVP, and a clear path to scale. Every choice maps to a specific ArshMind feature need.
Frontend
Framework
Next.js 14 (App Router) SSR for SEO on landing, CSR for dashboard. File-based routing maps cleanly to existing pages.
Language
TypeScript Full type safety across profile objects, scenario data, and API responses.
Styling
Tailwind CSS Port existing CSS variables as Tailwind theme tokens. Keep the COD aesthetic exactly.
State
Zustand Global store for profile, activeScenario, projections. Replaces all window.* globals and localStorage direct reads.
Charts
Recharts Replace custom canvas charts. React-friendly, responsive, accessible. Radar + Line + Bar all supported.
Auth UI
NextAuth.js v5 Handles Google OAuth + email magic link. Session cookie passed to all API calls.
Forms
React Hook Form + Zod Wizard validation. Zod schema shared with backend for end-to-end type safety.
Animations
Framer Motion Page wipe transitions, step reveals, analysis screen. Replaces CSS keyframe animations.
Backend / API
Runtime
Next.js Route Handlers API routes co-located with app. No separate Express server needed for v1. Add a standalone Node service for v2 if needed.
ORM
Prisma Type-safe DB client. Migrations tracked in version control. Schema-first design matches the ArshMind data model.
Validation
Zod Same schema used in frontend forms validates API inputs. Single source of truth.
Jobs
Inngest Background functions for: re-running projections nightly, sending milestone alerts, processing bank sync webhooks.
Payments
Razorpay India-first. Subscription API for Pro tier. Webhooks for subscription lifecycle events.
File Storage
Cloudflare R2 PDF export storage, avatar uploads. S3-compatible. Free egress.
Email
Resend Magic links, milestone notifications, weekly snapshot digest.
Database
Primary DB
PostgreSQL (Neon) Serverless Postgres. Branching for dev/staging. Free tier sufficient for 10k users.
Cache
Upstash Redis Cache AI projection results (expensive to compute). Rate-limit API calls. Session store.
Search
Postgres Full-text Search across user goals, context notes, and action plan tasks. pg_trgm for fuzzy match.
AI Layer
LLM
Claude claude-sonnet-4-20250514 Primary AI for projections, advisor chat, action plan generation, recommendation text.
Fallback
GPT-4o-mini Cheaper fallback for high-volume classification tasks (goal categorization, risk scoring).
SDK
Vercel AI SDK Streaming responses to frontend. Tool use for structured JSON output from projections.
Infrastructure / DevOps
Hosting
Vercel Next.js native. Edge functions for API. Auto-previews per PR.
CI/CD
GitHub Actions Lint → typecheck → test → deploy on merge to main.
Monitoring
Sentry + Vercel Analytics Error tracking and Core Web Vitals. Free tiers.
Secrets
Vercel Environment Variables Dev/preview/prod env separation. No .env in repo.

Architecture → Backend
API Endpoint Spec
All 18 route handlers. RESTful design, auth-protected, Zod-validated inputs, typed Prisma responses.
Authentication
Method + PathAuthDescription
POST /api/auth/signupPublicEmail + password signup. Returns session token.
POST /api/auth/loginPublicCredential or magic link login.
GET /api/auth/callbackPublicOAuth callback handler (Google, GitHub).
DELETE /api/auth/sessionAuthLogout — clears session cookie.
Profile
Method + PathAuthDescription
GET /api/profiles/meAuthFetch current user's full profile.
POST /api/profilesAuthCreate profile (wizard completion). Triggers AI projection job.
PATCH /api/profiles/meAuthUpdate any profile fields. Re-triggers projection if salary/savings changed.
DELETE /api/profiles/meAuthGDPR delete — removes profile + all projections + user account.
Projections
Method + PathAuthDescription
GET /api/projectionsAuthFetch all 6 scenario projections for current profile. Returns cached result if <24h old.
POST /api/projections/refreshAuthForce re-run AI engine on latest profile. Rate-limited: 3/day free, unlimited Pro.
GET /api/projections/:scenarioIdAuthSingle scenario detail with full yearly breakdown.
Goals & Action Plans
Method + PathAuthDescription
GET /api/action-plan/:scenarioIdAuthFetch month-by-month tasks for a scenario. AI-generated on first request.
PATCH /api/action-plan/tasks/:taskIdAuthMark task done/undone. Persisted to DB (not just DOM state).
POST /api/goals/customProCreate a custom goal beyond the default 10. Pro tier only.
AI Advisor
Method + PathAuthDescription
POST /api/advisor/chatProStreaming chat. Claude receives full user profile as context. Returns SSE stream.
GET /api/advisor/historyProFetch past chat sessions for current user.
Billing
Method + PathAuthDescription
POST /api/billing/checkoutAuthCreate Razorpay checkout session for Pro tier.
POST /api/billing/webhookPublic (signed)Razorpay webhook handler. Upgrades user tier on payment success.
DELETE /api/billing/subscriptionAuthCancel Pro subscription.

AI Layer Design
Replace hard-coded scenario modifiers with a real reasoning engine. Every AI call has a specific prompt structure, caching strategy, and fallback.
AI call map
FeatureModelTriggerCaching
Scenario projectionsClaude SonnetProfile save / manual refresh24h Redis, invalidated on profile change
Action plan generationClaude SonnetFirst view of action plan page7 days or until scenario changes
Smart recommendationsClaude SonnetDashboard load, weekly cron12h Redis
AI Advisor chatClaude SonnetUser message (Pro only)No cache — streamed live
Goal window textGPT-4o-miniProjection completeStored in DB with projection

Projection prompt structure
// System prompt injected once per session
You are a financial life planning AI for Indian professionals. You receive a user's complete financial and career profile and must return structured JSON projections for 6 life scenarios over a 10-year horizon. You reason like a CFP (Certified Financial Planner) combined with a career strategist familiar with the Indian job market, salary bands by city, and investment instruments (SIP, PPF, NPS, FD). Your projections must be realistic and contextual — not generic multipliers.
// User message
Profile: {JSON.stringify(profile)}
City salary benchmarks: {cityData[profile.city]}
Industry growth rates: {industryData[profile.industry]}

Return ONLY valid JSON matching the ProjectionResponse schema. No prose.
Advisor chat context injection
// System prompt for advisor chat
You are ArshMind Advisor — a personal financial and career strategist. The user's full profile, all their projections, and their selected life path are injected below. When they ask questions, reason specifically from their data. Never give generic advice. If their question is about a number, cite the specific projection value. If they describe a new idea (e.g. moving to Hyderabad, taking a sabbatical), model what that would do to their trajectory using the same logic as the projection engine.

User profile: {profile}
Active scenario: {activeScenario}
5yr projection: {projections[activeScenario].netWorth[year5]}
